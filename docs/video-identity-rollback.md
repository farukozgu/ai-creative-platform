# Cinematic restoration / identity rollback

The last Universal Product Identity Preservation task was removed with targeted file/hunk reversals. No reset, checkout, commit revert, database mutation, paid request, dependency change, commit or push was performed.

## Removed

- New identity inventory/schema, transcription/confidence processing and automatic conversion into Product Understanding branding regions.
- Extra Director identity inspection schema/context/instructions, identity plan fields, source-scale framing overrides and compiler identity sentences.
- New identity manifest/reference QA processing, PASS/FAIL/REVIEW evaluator, stored-report extension, library/detail badges and translations.
- New identity fixtures and request-fingerprint masking. The frozen regression now compares the actual full Director request directly with the existing baseline; expected hashes were not regenerated.

The original Product Understanding, existing visible branding/verified evidence, user-marked critical-region handling and pre-existing consented fidelity review are retained. Their original behavior is restored. Old receipts carrying the removed identity plan fields are rejected for replanning; signing algorithms and valid pre-identity receipts/cache keys are unchanged. No persisted source, review, video or payment records were rewritten.

## Preserved

Before rollback, 18 protected source/fixture files were fingerprinted; all remained byte-for-byte unchanged afterward. These include preset definitions, duration/quality strategies, signed receipt/runtime code, front/back reference binding, provider elements payload, source aspect-ratio handling and the existing provider/submission contracts. Prior Product Spotlight explicit-focus and benchmark contract corrections remain intact as unrelated preset quality/validation work.

The persisted successful sweater fixture and its five expected prompt hashes remain unchanged. Recompilation matches all five hashes, the complete compiled result and negative prompt; fallback reproduces the recorded shot plan. The frozen suite checks 2,689 Cinematic/other protected preset combinations and direct AI-request/cache fingerprints. The remaining three quality presets and all 24 presets' benchmark are exercised by the broader video suite.

## Logo reference regression

An authored embroidered-logo crop is supplied as an additional detail reference. Tests establish:

- Primary allowed evidence is unchanged; reference evidence stays separately available.
- Fallback keeps the original five beats: hero-reveal, material-study, controlled-motion, macro-detail, final-hero. No logo/text focus is injected.
- Adding the reference does not change fallback shot arrays for any 5/10-second single/multi combination.
- An authored AI plan retains those five camera/light/composition decisions through parser/compiler; the reference element contract and prompt bounds remain valid.
- Removed Product Understanding inventory metadata no longer creates extra logo/text regions.

These are offline regressions. They do not claim an unexecuted live model will always select the same shots. No new creative selection heuristic or identity/QA system was added.
